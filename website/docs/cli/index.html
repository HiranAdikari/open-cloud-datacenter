CLI Reference

dcctl is the command-line interface for the control plane. It talks to the same REST API documented under API, scoped to a tenant and project.

This page lists the real dcctl command tree, taken from the CLI source. Some descriptions still carry the upstream "Sovereign Cloud / Asgardeo" wording, pending a generic pass.

Install

shell
$ go install github.com/wso2/dcctl@latest

Verify the install and list the top-level command groups:

shell
$ dcctl --help

Global flags

These persistent flags apply to every command.

FlagDefaultDescription
-o, --outputtextOutput format.
--dcapi-url—Control-plane API base URL (overrides config).
-t, --tenantactiveTenant ID for this command.
--projectactiveProject ID for this command.

Example session

shell
$ dcctl login                 # OIDC PKCE flow
$ dcctl tenant set acme       # pick the active tenant
$ dcctl project set web       # pick the active project
$ dcctl vm create             # provision a VM (async, 202)
$ dcctl vm list               # watch it reach Active

auth

CommandDescription
dcctl loginAuthenticate with the identity provider (OIDC).
dcctl logoutClear stored credentials (~/.dcctl/credentials.json).

vm Manage virtual machines

CommandDescription
dcctl vm createCreate a virtual machine.
dcctl vm listList all virtual machines.
dcctl vm get <id>Get a virtual machine.
dcctl vm delete <id>Delete a virtual machine.

cluster Manage RKE2 clusters

CommandDescription
dcctl cluster createCreate an RKE2 cluster.
dcctl cluster listList all clusters.
dcctl cluster get <id|name>Get a cluster.
dcctl cluster delete <id|name>Delete a cluster.
dcctl cluster kubeconfig <cluster-id>Download kubeconfig for a cluster.
dcctl cluster node-pool add <cluster>Add a worker node pool to an ACTIVE cluster.
dcctl cluster node-pool scale <cluster> <pool>Scale a node pool to a new node count.
dcctl cluster node-pool list <cluster>List all node pools in a cluster.
dcctl cluster node-pool get <cluster> <pool>Get a single node pool.
dcctl cluster node-pool delete <cluster> <pool>Delete a worker node pool (drains nodes first).

vnet Virtual networks

CommandDescription
dcctl vnet create <name>Create a virtual network (VNet).
dcctl vnet listList all VNets.
dcctl vnet get <name-or-id>Get a VNet.
dcctl vnet delete <name-or-id>Delete a VNet.

subnet Subnets within VNets

CommandDescription
dcctl subnet createCreate a subnet within a VNet.
dcctl subnet listList subnets in a VNet.
dcctl subnet get <name-or-id>Get a subnet.
dcctl subnet delete <name-or-id>Delete a subnet.

peering VNet peerings

CommandDescription
dcctl peering createCreate a VNet peering.
dcctl peering listList peerings for a VNet.
dcctl peering get <name-or-id>Get a VNet peering.
dcctl peering delete <name-or-id>Delete a VNet peering.

network

CommandDescription
dcctl network listList available VM networks (legacy bridges).

image VM images

CommandDescription
dcctl image createUpload a VM image from a URL.
dcctl image listList available VM images.

bastion Bastion hosts

CommandDescription
dcctl bastion createCreate an SSH bastion host on a VPC.
dcctl bastion listList all bastion hosts.
dcctl bastion get <id>Get a bastion host.
dcctl bastion delete <id>Delete a bastion host.

keyvault Key Vaults

CommandDescription
dcctl keyvault create <name>Create a Key Vault (logical record).
dcctl keyvault listList Key Vaults for the active project.
dcctl keyvault get <id>Get a Key Vault by UUID.
dcctl keyvault delete <id>Delete a Key Vault.
dcctl keyvault credentials get <id>Retrieve AppRole credentials (shown once).
dcctl keyvault credentials rotate <id>Atomically rotate AppRole credentials (shown once).
dcctl keyvault secret put <vault-id> <key>Write a secret value.
dcctl keyvault secret get <vault-id> <key>Read a secret value.
dcctl keyvault secret list <vault-id>List secret names (values not included).
dcctl keyvault secret delete <vault-id> <key>Soft-delete a secret.
dcctl keyvault secret restore <vault-id> <key>Restore the latest soft-deleted version.
dcctl keyvault endpoint create <vault-id>Create a Private Endpoint into a tenant VPC.
dcctl keyvault endpoint get <ep-id>Get a Private Endpoint by UUID.
dcctl keyvault endpoint list <vault-id>List Private Endpoints for a Key Vault.
dcctl keyvault endpoint delete <ep-id>Delete a Private Endpoint.

tenant Selection, members, service accounts

CommandDescription
dcctl tenant listList all tenants the authenticated user can access.
dcctl tenant currentPrint the currently active tenant.
dcctl tenant set <tenant-id>Set the active tenant for subsequent commands.
dcctl tenant member create <user_sub>Invite a user to the tenant.
dcctl tenant member listList all human members of the tenant.
dcctl tenant member delete <user_sub>Remove a user from the tenant.
dcctl tenant service-account create <name>Create a new service account for the tenant.
dcctl tenant service-account listList all service accounts for the tenant.
dcctl tenant service-account delete <name-or-id>Delete a service account from the tenant.

project Projects within a tenant

CommandDescription
dcctl project create <project-id>Create a new project in the active tenant.
dcctl project get <project-id>Get a project by ID.
dcctl project listList all projects in the active tenant.
dcctl project update <project-id>Update a project's capacity quotas.
dcctl project delete <project-id>Delete a project.
dcctl project currentPrint the currently active project for the current tenant.
dcctl project set <project-id>Set the active project for the current tenant.

admin Platform-admin

CommandDescription
dcctl admin tenant create <tenant-id>Register a new tenant (platform-admin only).
dcctl admin tenant cap show <tenant-id>Show the current capacity cap for a tenant.
dcctl admin tenant cap set <tenant-id>Adjust a tenant's capacity cap (platform-admin only).
