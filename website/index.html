What it is

One control plane for the infrastructure you already own.

OpenStrato turns private and on-prem infrastructure into a self-service cloud — no Terraform to hand-write, no virtualization internals to touch.

One API, CLI & console

Provision and manage every resource the same way, whether you script it, type it, or click it.

Spec-driven

A single OpenAPI contract is the source of truth — the API, CLI, and console never drift apart.

Pluggable providers

KubeVirt for VMs, RKE2 for clusters, and more — swap the substrate without changing your workflow.

Sovereign by design

Runs entirely in your datacenter. No public-cloud dependency, no data leaving your walls.

Capabilities

Everything a platform team needs to self-serve.

Compute

Provision VMs with sizes, images, and disks. Start, stop, resize, and snapshot — backed by KubeVirt.

Kubernetes clusters

Stand up conformant clusters with managed node pools and a kubeconfig in minutes — powered by RKE2.

Networking

Define virtual networks, subnets, and security groups. Private IPs and isolation, declaratively.

Tenancy & RBAC

Multi-tenant by default. Scope quotas, roles, and resources per team with fine-grained access control.

One contract

One control plane, three ways to drive it.

The API, CLI, and console are generated from the same OpenAPI spec. Pick whichever fits the moment.

curl · REST
curl -X POST https://ocd.internal/v1/vms \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"name":"web-01","size":"medium","image":"ubuntu-22.04"}'

# 201 Created
{ "id": "vm-7f3a91", "status": "Creating", "ip": null }

Architecture

A spec-driven core with pluggable providers.

The control plane holds the OpenAPI contract and desired state. Providers reconcile that state onto your real infrastructure.

Why OpenStrato

Cloud ergonomics, on infrastructure you control.

Sovereign & on-prem

Everything runs in your datacenter. No egress, no external dependency, full data residency.

Spec-driven, no drift

One OpenAPI contract generates every surface, so the API, CLI, and console stay perfectly in sync.

Multi-tenant

Isolate teams with tenants, scoped quotas, and RBAC — without standing up separate stacks.

Self-service

Get started

Up and running in minutes.

Local · minutes

Quick start

Spin up a local control plane to explore the API, CLI, and console on your laptop.

bash
$ curl -sSL https://get.openstrato.dev | sh
$ dcctl up --local
Read the quickstart
Production

Install on your cluster

Deploy the control plane and providers onto an existing Kubernetes cluster with Helm.

bash
$ helm repo add ocd https://charts.openstrato.dev
$ helm install ocd ocd/control-plane \
    -n ocd-system --create-namespace
